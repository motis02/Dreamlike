# RandomDreamGenerator 随机梦境生成器
一个充满浪漫和想象力的小工具，每次运行都能生成一个完全不重样的奇妙梦境，还能自动生成对应梦境的治愈系插画，帮你把奇思妙想变成可以收藏分享的完整梦境作品。

## 功能特点
- ✨ 完全随机组合，几乎不会生成重复的梦境
- 🎨 自动根据梦境内容生成专属的治愈系童话风插画
- 📝 生成的梦境自带唯一ID，方便你收藏和分享
- 🚀 依赖极少，安装完 pillow 和 requests 就能直接运行

## 快速开始
1. 克隆项目到本地
```bash
git clone https://github.com/你的用户名/RandomDreamGenerator.git
cd RandomDreamGenerator
 

安装依赖


pip install pillow requests
 

直接运行代码


python dream_generator.py
 

自定义扩展
你可以直接修改代码里的元素列表，加入你自己喜欢的场景、角色和事件，还可以调整绘画提示词的风格，生成完全贴合你喜好的专属梦境~
